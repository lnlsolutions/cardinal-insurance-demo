How the pull works

Three connection types, same normalized output.

API  Carrier-issued API credentials. Real time, no markup, includes documents.

Rater  Comparative rater or agency management bridge. Rates and policy data in one call.

Portal  Carrier portal session with stored agency login and MFA handshake. Slower, still normalized.
